# 每日健身计划（离线单文件网页 App）

一个**零依赖、可完全离线运行**的健身计划 App。填写身高、体重、目标与训练条件，它会生成一份**精确到每一天、可以一直练下去**的训练计划，并提供动作示意动画、每日饮食配餐、伤病替代与训练后反馈自适应。

在线访问：https://ynz24522-creator.github.io/fitness-plan/

整个 App 由 5 个本地文件组成，不需要安装任何东西，不需要联网，也没有后端和账号体系。把这 5 个文件放在同一个目录里，双击 `index.html` 即可使用。

## 为什么是"连续"的计划

大多数计划工具只给你一份固定的动作清单，练完就没了。这个 App 的计划是**无限延续**的：每一天（包括休息日）都有明确安排，训练按周推进、每 4 周为一个中周期，可以一直用下去。

计划以**训练日序数**索引，而不是日历周。这意味着漏练不会打乱计划节奏——今天没练，明天的内容会自动顺延上来，分化顺序不会错位。

## 功能

- **精确到天**：训练日和休息日都有具体安排，休息日给出主动恢复建议
- **训练日自己定**：每周练几天、练周几都能自由选择（1–7 天），也可一键套用推荐排布再微调
- **动作示意动画**：每个动作配一段矢量火柴人动画，展示主要关节轨迹，点击可放大；弹层里另附真人示范视频链接
- **每日饮食配餐**：按年龄性别算基础代谢与每日消耗，结合增肌/减脂/塑形/增力目标给出热量、三大营养素与三餐（或三餐+两次加餐）的具体食物组合
- **伤病自动替代**：勾选受限部位后，涉及该部位的动作自动跳过并给出安全替代建议，计划照常继续不会中断
- **反馈自适应**：每次练完记录完成度、主观强度、疼痛与疲劳，满一周自动结算，调整下周的负重、组数与组间休息
- **无限延续**：计划没有终点，第 5 周、第 50 周都有内容
- **四周中周期**：第 1–3 周逐步加量，第 4 周主动减载恢复，进入下一周期整体再提升约 3%
- **按身体数据定制**：BMI 分档决定动作库与冲击量，体重百分比决定起始配重，身高影响动作幅度与替代动作
- **三种训练场地**：居家徒手、居家哑铃、健身房，同一套递进逻辑适配三套动作库
- **自动顺延**：漏练或主动跳过都不改变训练日序号，计划不会中断
- **打卡与连击**：训练日和休息日都能打卡，统计连续打卡天数
- **组间计时器**：内置倒计时，结束时用 WebAudio 合成提示音（不需要音频文件）
- **数据本地保存**：所有记录存在浏览器本地存储里，不上传任何服务器

## 身高体重是怎么影响计划的

身体数据不是用来展示的，它真的参与计划生成：

| 维度 | 计算方式 | 对计划的影响 |
| --- | --- | --- |
| BMI | 体重 ÷ 身高² | 分四档：偏瘦（<18.5）、正常（18.5–23.9）、超重（24–27.9）、肥胖（≥28） |
| 肥胖档 | BMI ≥ 28 | **剔除全部跳跃冲击动作**（开合跳、跳绳、波比跳），替换为快走、原地踏步、臀桥、靠墙静蹲等关节友好方案；减脂日的有氧收尾改为长时间快走 |
| 超重档 | BMI 24–27.9 | 跳跃类替换为低冲击版本，并提示控制膝关节角度 |
| 偏瘦档 | BMI < 18.5 | 减少长时间有氧，侧重力量与增肌，建议加长组间休息 |
| 体重 | 相对体重的负重系数 | 决定哑铃/杠铃/器械的推荐重量，再按经验等级与递进系数缩放 |
| 身高 | 偏矮（<165） | 行程较短，建议在可控范围内多完成 1–2 次补足刺激（增力主项除外） |
| 身高 | 偏高（>180） | 长行程，深蹲/硬拉起始重量下调 10% 并提示用箱式深蹲、架上硬拉；用高位下拉替代引体向上 |

配重还会按场地取整：居家哑铃取最近的 0.5 kg 档位，杠铃取 2.5 kg 档位，并从空杆重量起步。

## 训练参数

分化结构由每周训练天数决定，训练经验只调节组数与动作难度层级。**具体练周几完全由你自己选**，下表里的排布只是「推荐预设」快捷按钮的默认值，选完还能单独开关任意星期：

| 每周天数 | 分化 | 推荐预设 |
| --- | --- | --- |
| 1 天 | 全身综合 | 周三 |
| 2 天 | 全身 A / B | 周一、周四 |
| 3 天 | 全身 A / B / C（新手）或 推 / 拉 / 腿（中级以上） | 周一、周三、周五 |
| 4 天 | 上肢 A、下肢 A、上肢 B、下肢 B | 周一、周二、周四、周五 |
| 5 天 | 推、拉、腿、上肢、下肢 | 周一、周二、周三、周五、周六 |
| 6 天 | 推 A、拉 A、腿 A、推 B、拉 B、腿 B | 周一至周六 |
| 7 天 | 推拉腿两轮 + 恢复日（第 7 天低强度，组数压到 2 组） | 周一至周日 |

训练日序号是按你实际选择的训练日顺序连续编号的，所以无论怎么组合，漏练顺延与四周中周期的递进节奏都不受影响。

次数区间与组间休息由训练目标决定：

| 目标 | 次数 | 组间休息 |
| --- | --- | --- |
| 减脂 | 12–15 次 | 45 秒 |
| 增肌 | 8–12 次 | 75 秒 |
| 塑形 | 10–12 次 | 60 秒 |
| 增力 | 主项 4–6 次 / 辅助 8–10 次 | 120 秒 / 90 秒 |

组数按经验等级与中周期周次递进（例如中级为 3、3、4 组，第 4 周减载回落到 2 组）；徒手动作无法加重量时，改为每两个中周期增加 1 组，最多加 2 组。

## 打卡、连击与顺延

- 训练日打卡记为「完成训练」，休息日打卡记为「完成恢复」，两者都算有效打卡
- 连续自然日都有打卡则连击天数 +1，中断则重新从 1 开始
- 漏练或点击「今天跳过」都不会推进训练日序号，同一份训练内容会等到下一个训练日
- 只有完成打卡后，训练日序号才前进

## 动作示意与视频

每个动作卡片左侧有一段 SVG 火柴人动画，演示该动作的主要关节轨迹（14 类动作模式，覆盖全部 82 个动作）。动画由代码逐帧计算关节角度绘制，因此**完全离线可用、体积只有几十 KB**，也不会出现动作画错的问题。

点击动画可以放大查看，弹层里除了放大的示意图与文字要领，还有「看真人示范」链接，跳转到 B 站搜索该动作的标准示范视频。这部分需要联网，断网时其余功能不受影响。

> 动作示意只展示关节轨迹的骨架，不替代真人示范。细节以文字要领和真人视频为准。

## 饮食推荐

在「我的」里补充年龄与性别后，「饮食」页会按 **Mifflin-St Jeor** 公式计算基础代谢，再按你的每周训练天数取活动系数，得到每日消耗，最后结合训练目标给出热量目标：

| 目标 | 热量 | 蛋白质 | 脂肪占比 |
| --- | --- | --- | --- |
| 减脂 | 每日消耗 × 0.80（不低于基础代谢 × 1.10） | 1.9 g/kg | 25% |
| 增肌 | 每日消耗 × 1.12 | 1.7 g/kg | 25% |
| 塑形 | 每日消耗 × 0.95 | 1.8 g/kg | 27% |
| 增力 | 每日消耗 × 1.05 | 1.7 g/kg | 28% |

- 训练日热量 +8%、休息日 −6%（每周训练 ≥6 天时不做波动），相对差约 15%
- BMI ≥ 30 时蛋白质按矫正体重计算（理想体重 + 0.25 × 超出部分），避免目标失真
- 支持纯素 / 蛋奶素，以及忌海鲜、坚果、乳制品、牛肉、猪肉、辛辣的过滤
- 配餐从约 70 种中式食材中组合，自动微调份量使总热量误差 ≤8%、蛋白质达到目标的 95% 以上
- 用「日期 + 档案」做确定性种子，同一天刷新结果一致；不满意可以点「换一套」重新组合

> 配餐是通用营养参考，不构成医疗或营养处方。糖尿病、肾病、孕期等情况请遵医嘱。

## 伤病替代

可标记 8 个部位：颈、肩、肘、腕、腰、髋、膝、踝足。限制来源有两处：

- **常驻**：在「我的」里勾选，长期生效
- **临时**：在「今日」页点一下，只影响当天

生成计划时会剔除所有涉及受限部位的动作。如果某个动作模式下的动作全部受限（例如腰椎不适时的硬拉类），该项会替换为「今日跳过 + 该部位安全替代与恢复建议」——**这一天仍然是有效训练日，可以正常打卡，训练日序号照常推进**，因此计划不会中断。

## 反馈自适应

打卡时会弹出反馈表单（完成度、主观强度四档、是否有疼痛、疲劳与睡眠），默认值已经选好，不想填可以直接「跳过反馈，直接打卡」。数据只存在浏览器本地。

满一周后按下表结算，命中一条即停止，结果叠加在四周中周期之上（负重 = 基础配重 × 中周期系数 × 自适应系数）：

| 上周反馈 | 本周调整 |
| --- | --- |
| 出现疼痛 | 负重 ×0.9、组数 −1、休息 +15 秒，并把该部位加入下次训练的临时规避 |
| 平均强度 ≥8.5 或完成度不足 | 负重 ×0.92、组数 −1、休息 +10 秒 |
| 实际训练次数不足计划的 60% | 不调整（不进阶） |
| 平均强度 ≤5.5 且全部完成 | 负重 ×1.05、组数 +1、休息 −5 秒 |
| 其余情况 | 保持中周期原计划 |

累积调整有保护区间：负重系数限制在 0.70–1.15，组数增量限制在 −2~+2，最终组数限制在 2–6 组。

## 快速开始

### 在线使用

打开 https://ynz24522-creator.github.io/fitness-plan/ 即可，手机上也能直接用。

### 本地使用

下载仓库后直接双击 `index.html` 就能运行（`app.css`、`app.js`、`plan-engine.js`、`diet-engine.js` 需要和它放在同一目录）。

> **Safari 用户注意**：Safari 会限制 `file://` 页面使用本地存储，导致打卡记录无法保存。此时在仓库目录下执行 `python3 -m http.server 8000`，然后访问 http://localhost:8000/ 即可正常保存。（Chrome、Edge 双击打开通常没有问题。）

## 项目结构

```
.
├── index.html                  # 页面骨架（双击这个文件即可使用）
├── app.css                     # 全部样式
├── plan-engine.js              # 训练计划引擎 + 伤病映射 + 反馈自适应（纯逻辑，可在 Node 中直接测试）
├── diet-engine.js              # 代谢计算 + 食物库 + 配餐（纯逻辑）
├── app.js                      # 界面层 + 动作示意动画
├── tests/
│   ├── test-engine.mjs         # 训练引擎断言（分档、排布、递进、顺延、配重、伤病、自适应…）
│   ├── test-diet.mjs           # 饮食引擎断言（代谢、宏量、忌口过滤、配餐精度、确定性…）
│   └── smoke-ui.mjs            # 界面冒烟测试（最小 DOM 桩，逐页签渲染并模拟打卡与反馈）
├── LICENSE
└── .nojekyll                   # 让 GitHub Pages 原样发布静态文件
```

`plan-engine.js` 与 `diet-engine.js` 都是不依赖 DOM 的纯函数模块，挂在 `globalThis.PlanEngine` 与 `globalThis.DietEngine` 上，因此测试脚本可以直接在 Node 里加载，不需要浏览器。

## 开发与测试

`index.html` 里的计划引擎写在 `<script id="plan-engine">` 中，是一组不依赖 DOM 的纯函数。测试脚本会把它抽出来在 Node 里直接执行，所以不需要浏览器环境。

```bash
node tests/test-engine.mjs    # 705 项断言：分档边界、自定义训练日、中周期递进、顺延、配重档位、伤病剔除、自适应规则…
node tests/test-diet.mjs      # 124 项断言：代谢公式、宏量分配、素食与忌口过滤、配餐精度、结果确定性…
node tests/smoke-ui.mjs       #  97 项断言：四个页签渲染、星期开关、动作弹层、饮食页、伤病开关、反馈弹层与打卡写库
```

界面测试用一个最小 DOM 桩执行真实界面脚本（包括解析渲染结果来驱动星期开关、快捷预设与反馈弹层），并注入固定时钟（2026-09-11 周五），保证断言不随运行日期变化。

## 数据与隐私

- 所有数据保存在浏览器 `localStorage`（键名 `fitnessPlan.v1.profile` 与 `fitnessPlan.v1.progress`）
- 没有账号、没有后端、没有任何网络请求，页面里不含任何外部链接或追踪脚本
- 清除浏览器数据会同时清除打卡记录，「我的」页签里也有清除按钮

本工具提供的训练建议基于通用健身原则，**不构成医疗建议**。如有伤病、心血管疾病、孕期或慢性疾病，请先咨询医生或专业教练。训练中如出现疼痛、眩晕等不适，请立即停止。
